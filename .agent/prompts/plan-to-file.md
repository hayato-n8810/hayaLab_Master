# Plan to File

計画を作成し、`.agent/plans/` にファイル保存したいときに使用する。

実行計画を作成し、`.agent/plans/` 配下にファイルとして保存する。

要件:
1. 依頼内容から短いトピック名を決める。
2. `YYYY-MM-DD-<short-topic>.md` 形式でファイル名を作成する。
3. 以下の順でセクションを記述する。
   - Goal
   - Assumptions
   - Steps
   - Validation
   - Risks
4. 各セクションは簡潔かつ実行可能な内容にする。
5. 情報が不足している場合は、停止せず前提を明示して進める。
