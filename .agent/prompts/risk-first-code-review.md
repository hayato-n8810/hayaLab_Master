# Risk-First Code Review

バグ・回帰・危険な前提・テスト不足を優先してコードレビューしたいときに使用する。

リスク優先のコードレビューを実施する。

レビュー優先順位:
1. 正しさに関わるバグ
2. 挙動回帰
3. データ / スキーマ互換リスク
4. 再現性とパス前提
5. テスト不足・テスト弱度

出力形式:
1. 指摘事項（重大度順）
2. 各指摘のファイル参照
3. 未確定事項と前提
4. 変更全体のリスク要約

ルール:
- 指摘は具体的かつ実行可能にする。
- スタイル指摘より、根拠のあるリスク指摘を優先する。
- 問題なしの場合も残留リスクとテストギャップを明示する。
